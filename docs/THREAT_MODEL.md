# 威胁模型

## 保护目标

所选文件可能包含作者、设备、时间、GPS、来源、批注和容器附加数据。FileVeil 对支持的结构进行定位，并在保守策略允许时生成新文件。原件内容的 SHA-256 用于操作前后对照。

## 输入与信任边界

文件输入均视为不可信。解析 JPEG 标记和 PNG 块时检查边界与 CRC。Office 输入经过 ZIP 限额、路径与名称冲突检查，再解析 OPC 关系和 XML。解析过程不会执行宏、脚本或外部链接。

生成的报告提供结构位置与处理状态。默认不输出元数据值、文件正文和输入绝对路径。输出文件名仍可能包含调用方选择的名称，报告应按文件名的敏感程度保存。

## 对手能力

- 接收者可以读取标准元数据和操作系统属性。
- 取证工具可以检查容器成员、文件尾、修订、嵌入对象和未知字段。
- 厂商可能拥有内容级或文本统计水印检测密钥。
- 恶意输入可以尝试越界、压缩炸弹、XML 实体、路径穿越及资源耗尽。

## 可执行范围

JPEG/PNG 默认处理明确识别的隐私元数据，保留编码图像和色彩相关结构。Office Safe 处理已知属性并保留正文、公式、媒体及批注。Deep 按显式选择清理受支持的修订、批注与隐藏内容。独立验证重新读取输出并对照保留内容。

未知结构、批注、外部关系和嵌入内容可能继续携带隐私数据。报告说明保留项，资源超限或无法保护的结构会阻断处理。操作系统安全来源标记应传播至副本，传播失败时阻断提交。

## 未评估范围

内容中的人脸、背景、可见文字和文风保持未评估。公开 LSB、SD1/SDXL 与 FileVeil DCT 协议采用各自检测和清理验证范围。C2PA 离线验签与 PDF 完整重写覆盖实现规定的容器和验证范围。厂商私有检测器、未知内容水印、私有文本统计水印和音频信号方案保持未评估。任何元数据处理结果都不构成身份匿名性证明。

## 0.3 扩展信任边界

MCP 客户端受服务端显式读取/输出目录约束。目录授权不会授予原件写权限。符号链接、硬链接、路径穿越、输出重定向和根目录替换有独立检查，输入快照绑定已打开的文件句柄。父进程拥有私有暂存与 PDF helper 输入，取消时回收整个进程树并清理敏感快照。

PDF 由成熟 qpdf 后端解析和完整重写，独立 Poppler 可验证页面、文本和渲染。结构有效与元数据删除的证据只覆盖声明范围，流中的任意敏感内容、签名信任和复杂主动内容存在独立结论。Deep 内容删除由调用者逐项选择，签名和加密仍受到保护。

C2PA 签名、资产绑定与信任根分别判定，来源凭据与隐形追踪信号分开报告。合成 LSB 检测器只证明公开协议的可复现识别能力，Diff Lab 保留正常编码、传感器噪声和处理痕迹等解释空间。静态插件契约授予已授权快照的只读访问。

## 0.4 签名与历史标记边界

Heritage 的 Ed25519 公钥随记录携带，信任锚由本地策略明确提供。首个签名密钥对应本条记录的持有人，发行阈值由记录策略和本地信任共同约束。作者、版本和离线时间属于用户声明，完整历史需外部已知检查点。公开 DCT 作品引用消息可被复制，来源认证由签名、资产绑定与信任分别判断。

私钥文件采用未加密本地格式，读取检查所有者、权限与链接身份。MCP 对签名密钥实施逐文件白名单，密钥同时需要位于授权读取目录。持有本地签名权限的客户端可以签署声明，授权范围应按实际签名用途配置。

Red Star 兼容性有公开真实样本支持。Woolim 和 Pyongyang 签名结构解析保留密码学未评估状态。Pyongyang 320B 清理只验证静态 ABI 的四项结构条件及保留内容，真实设备 RSA 签名与身份归属仍待原始样本、密钥和信任依据。
