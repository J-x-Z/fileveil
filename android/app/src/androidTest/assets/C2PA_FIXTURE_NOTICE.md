# Synthetic C2PA fixtures

These FileVeil-owned MPL-2.0 samples are generated by the ignored `regenerate_public_fixtures` integration test. It creates temporary ES256 keys and X.509 test certificates with OpenSSL, signs 4×4 synthetic PNG/JPEG images with c2pa 0.91.11, then removes the private keys through TempDir. The ordinary tests read the committed public samples and run entirely offline.

The separate `regenerate_document_fixtures` test creates a one-page PDF, UTF-8 plain text with an A.8 variation-selector wrapper, and Markdown with an A.9 dedicated comment wrapper. It retains a separate `document-root.pem` public trust root and removes its temporary private keys. These document handlers are explicitly enabled experimental features of the pinned official SDK. FileVeil verifies A.8 NFC binding only for already-NFC text. Its removable A.9 subset requires a complete dedicated comment on the first physical line. The fixtures include CRLF, emoji variation selectors and legitimate language format characters so exact-byte preservation is exercised.

`regenerate_audio_fixtures` generates the separate `signed.wav` and `audio-root.pem` public samples. The WAV contains four synthetic mono 16-bit PCM samples at 8 kHz and a standard RIFF `C2PA` chunk. Its private signing key is removed with the temporary directory. Ordinary tests validate its signature and binding offline, mutate a sample byte, and check that container metadata rewriting stays blocked.

`regenerate_media_fixtures` signs the four FileVeil-owned native codec samples documented in `../../../../../tests/fixtures/MEDIA_PROVENANCE.md`. These MPL-2.0 assets originate from synthetic pixels and frames encoded with macOS ImageIO/AVFoundation. The public `signed.heic`, `signed.avif`, `signed.mp4` and `signed.mov` samples total less than 18 KiB. A separate `media-root.pem` test root authorizes their ephemeral ES256 signer. Private keys are removed with the temporary directory. Offline regressions verify COSE signatures, BMFF hash bindings and explicit root trust, then independently mutate a claim and a media-data byte to test failure reporting.

The public roots define test-only trust policies. FileVeil loads a trust bundle only when explicitly supplied by the caller. `remote.png` contains an unreachable example.invalid provenance reference used to verify disabled remote retrieval. Tampered copies are constructed in memory by the tests.
